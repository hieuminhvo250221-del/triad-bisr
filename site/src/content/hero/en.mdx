An embedded 256-word SRAM built around an unmodified OpenRAM macro on SkyWater sky130. After a start
pulse it tests itself, works out an exact repair from three resources (spare words, spare columns that
can be steered differently in each address partition, and a programmable number of words left to the
error-correcting code), programs the repair and verifies it. The design is taken from RTL to GDS with
open-source tools; the layout still has open sign-off items, listed below.
